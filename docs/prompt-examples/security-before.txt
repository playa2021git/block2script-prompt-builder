Block2Script用プログラム作成のお願い

以下の装置構成と動作条件に基づいて、現在使用しているBlock2Script環境で実行可能なプログラムを作成してください。通常のJavaScriptや外部APIを勝手に使用しないでください。現在ロードされている命令や拡張機能で対応できない場合は、その内容を説明してください。必要な変数やリストがある場合は、作成前の準備として名前と用途を明示してください。

【作りたい装置】
暗いときに人を検知し、AI分類結果に応じて動作を変える防犯装置の模型。実際の住宅の鍵は制御しない。

【S：使用するセンサ】
S1：明るさセンサ
  接続方式：micro:bit内蔵
  内蔵のため外付け端子の指定なし
  B2S対応状況：Microbit Moreに対応命令あり（実機確認は別途必要）
S2：人感センサ HC-SR505
  接続方式：デジタル入力
  信号（OUT）：P0
  B2S対応状況：汎用の入出力命令あり。装置の配線・電源・動作は先生と確認

【A：使用するアクチュエータ】
A1：スピーカー
  接続方式：micro:bit内蔵
  内蔵のため外付け端子の指定なし
  B2S対応状況：Microbit Moreに対応命令あり（実機確認は別途必要）
  注意：本体スピーカーはmicro:bit V2の機能です。
A2：180°サーボモータ（SG90）
  接続方式：サーボ信号
  信号（サーボ）：P1
  B2S対応状況：汎用の入出力命令あり。装置の配線・電源・動作は先生と確認
  注意：電源とGNDの接続も先生と確認してください。
A3：5×5 LED
  接続方式：micro:bit内蔵
  内蔵のため外付け端子の指定なし
  B2S対応状況：Microbit Moreに対応命令あり（実機確認は別途必要）

【Teachable Machine】
種類：画像認識
Class名（次のJSON配列の各文字列を、大文字・小文字・前後の空白も含めてそのまま使ってください）：
["家の人","クロネコヤマト","怪しい人"]
モデルURL：未入力。必要な場合は設定方法を説明してください。
対応状況：TM2Scratchに画像モデルURL・ラベル・イベントの命令あり。

【実現したい動作】
明るさが30未満でHC-SR505が人を検知したら画像分類する。「家の人」はサーボで鍵の模型を180度へ動かす。「クロネコヤマト」はスピーカーとLEDで配送を知らせる。「怪しい人」は警告音とLEDで知らせる。サーボは0度と180度を使う。音の高さや画面の演出は未指定。模型の停止・再動作・異常時の扱いは安全を優先する。

【コード作成前に確認したいこと】
・S2 人感センサ HC-SR505：汎用の入出力命令あり。装置の配線・電源・動作は先生と確認
・A2 180°サーボモータ（SG90）：汎用の入出力命令あり。装置の配線・電源・動作は先生と確認
・モデルURLは未入力です。必要な設定をGemに確認してもらいます。

【作成時のお願い】
・記載のない装置・端子・Class名・動作時間・しきい値・再動作条件を推測で決めないでください。不足する情報があれば、コードの前に質問してください。
・装置の対応は、現在のBlock2Scriptの命令仕様と読み込み済み拡張で確認してください。MakeCodeのブロックをそのままB2Sの命令と扱わないでください。
・準備する拡張機能、変数・リスト、貼り付けるBlock2Script Script、動作確認の順で説明してください。
