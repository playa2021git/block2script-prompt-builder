# 動作確認

2026-11-12、LinuxのChromiumで確認。

- ロジックテスト13件成功：必須、S/A区分、複数台、Classの完全保持・空行・重複、候補外端子、TRIG/ECHO、I2C共有と同一アドレス、保存復元・破損データ、未使用AIの除外、未確認条件。
- ブラウザーテスト成功：サンプル、未入力のエラー、ポンプ端子入力、生成、実クリップボードへのコピー、編集済み指示文の再読込復元、入力変更後のコピー防止、AI非表示、Class空白・重複、センサ削除、端子重複、コピー禁止時の手動案内、保存禁止・破損データ。
- 1366×960と390×844で表示と横方向のはみ出しがないことを確認。スクリーンショットを目視確認。
- `/block2script-prompt-builder/`配信で同じブラウザーテストが成功。
- ブラウザーのpageerrorなし。通常操作で外部へのリクエストなし。入力文字列のHTMLタグが実行されず、文字列として保持されることも確認。

実Chromebook・実スマートフォン、授業ネットワーク、専用Gem、micro:bit実機・専用ファームウェア・ポンプは未検証。生成するのはGemへの指示文であり、プログラムや実機の動作をこのアプリだけで保証しない。

## 発明ワークショップへの移行

`npm test` の既存13件に加え、`npm run test:browser` で旧ブラウザーテスト（切り替え式パネルの導線へ移植）と新しいワークショップテストを実行します。通常・GitHub Pages形式のサブディレクトリ配信で検証しています。装備欄の編集・削除・即時更新、端子競合、生成文との一致、旧保存形式、4画面幅、キーボード、アニメーション抑制を追加しました。設計とスクリーンショットの一覧は [workshop-ui.md](workshop-ui.md) を参照してください。
